   a) buildGameOverSubtitle() method now generates subtitle containing:

      - MAP: [map name] (DIFF: [difficulty])
      - MAZES: [mazes cleared]
      - HEARTS: [extra hearts earned]

   b) CanvasPanel.paintComponent() updated to handle multi-line subtitle:

   c) Added game over key bindings:
      - ESCAPE: Returns to main menu
      - 'L' key: Opens leaderboard
      - ENTER: Plays again (starts new game)
